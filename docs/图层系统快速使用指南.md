# 图层系统快速使用指南

## 快速开始

### 1. 在 HTML 中使用

```html
<!DOCTYPE html>
<html>
<head>
    <title>图层系统示例</title>
</head>
<body>
    <canvas id="canvas" width="800" height="600"></canvas>

    <script type="module">
        import init, { LayerStack, initThreadPool } from './pkg/photon_wasm.js';

        // 初始化
        await init();
        await initThreadPool(4);

        // 创建图层堆栈
        const stack = new LayerStack(800, 600);

        // 添加图层
        const layer1Id = stack.add_layer("背景");
        const layer2Id = stack.add_layer("前景");

        // 获取并修改图层
        const layer = stack.get_layer(layer2Id);
        layer.opacity = 200;
        layer.blend_mode = 2; // Screen

        // 合成并显示
        const composite = stack.render_composite();
        const base64 = composite.get_base64();

        const img = new Image();
        img.onload = () => {
            const ctx = document.getElementById('canvas').getContext('2d');
            ctx.drawImage(img, 0, 0);
        };
        img.src = base64;
    </script>
</body>
</html>
```

### 2. 在 Node.js 中使用

```javascript
const { LayerStack, initThreadPool } = require('./pkg/photon_wasm.js');

// 初始化
await initThreadPool(4);

// 创建图层堆栈
const stack = new LayerStack(800, 600);

// 添加图层
const id = stack.add_layer("我的图层");

// 获取图层信息
console.log("图层数量:", stack.layer_count);
console.log("图层 IDs:", stack.get_layer_ids());
console.log("图层名称:", stack.get_layer_names());
```

## API 参考

### LayerStack

#### 构造函数
```javascript
const stack = new LayerStack(width, height);
```

#### 添加图层
```javascript
// 添加空白图层
const id = stack.add_layer("图层名称");

// 从像素数据添加图层
const pixels = new Uint8Array(width * height * 4);
// ... 填充像素数据 ...
const id = stack.add_layer_from_pixels(pixels, "图层名称");
```

#### 获取图层
```javascript
// 通过 ID 获取
const layer = stack.get_layer(id);

// 通过索引获取（0 = 最底层）
const layer = stack.get_layer_by_index(index);
```

#### 图层列表
```javascript
const ids = stack.get_layer_ids();
const names = stack.get_layer_names();
const visibility = stack.get_layer_visibility(); // 0 = 不可见, 1 = 可见
const opacities = stack.get_layer_opacities();
```

#### 删除图层
```javascript
// 通过 ID 删除
stack.remove_layer(id);

// 通过索引删除
stack.remove_layer_by_index(index);

// 清空所有图层
stack.clear_all();
```

#### 移动和复制
```javascript
// 移动图层
stack.move_layer(fromIndex, toIndex);

// 复制图层
const newId = stack.duplicate_layer(id);
```

#### 合并图层
```javascript
// 向下合并
stack.merge_down(index);

// 合并所有可见图层
stack.flatten();
```

#### 合成图像
```javascript
const composite = stack.render_composite();
const base64 = composite.get_base64();
const bytes = composite.get_bytes();
```

### Layer

#### 属性
```javascript
const layer = stack.get_layer(id);

// 只读属性
console.log(layer.id);           // 图层 ID
console.log(layer.name);         // 图层名称
console.log(layer.width);        // 图层宽度
console.log(layer.height);       // 图层高度

// 可读写属性
layer.visible = true;            // 可见性
layer.locked = false;            // 锁定状态
layer.opacity = 200;             // 不透明度 (0-255)
layer.blend_mode = 2;            // 混合模式
```

#### 像素操作
```javascript
// 获取像素数据
const pixels = layer.get_pixels();

// 设置像素数据
layer.set_pixels(pixels);
```

### 混合模式

```javascript
// 可用的混合模式
const BlendMode = {
    Normal: 0,
    Multiply: 1,
    Screen: 2,
    Overlay: 3,
    SoftLight: 4,
    HardLight: 5,
    Difference: 6,
    Exclusion: 7,
    Lighten: 8,
    Darken: 9
};

// 使用示例
layer.blend_mode = BlendMode.Screen;
```

## 实用示例

### 示例 1: 创建多层图像

```javascript
// 创建图层堆栈
const stack = new LayerStack(800, 600);

// 添加背景图层
const bgId = stack.add_layer("背景");
const bg = stack.get_layer(bgId);
const bgPixels = bg.get_pixels();
// ... 填充背景像素 ...
bg.set_pixels(bgPixels);

// 添加前景图层
const fgId = stack.add_layer("前景");
const fg = stack.get_layer(fgId);
fg.blend_mode = 2; // Screen
const fgPixels = fg.get_pixels();
// ... 填充前景像素 ...
fg.set_pixels(fgPixels);

// 合成图像
const composite = stack.render_composite();
```

### 示例 2: 调整图层顺序

```javascript
// 获取当前图层顺序
const ids = stack.get_layer_ids();
console.log("当前顺序:", ids);

// 将第一个图层移到最上层
stack.move_layer(0, ids.length - 1);

// 检查新顺序
console.log("新顺序:", stack.get_layer_ids());
```

### 示例 3: 批量处理图层

```javascript
const ids = stack.get_layer_ids();

// 设置所有图层的不透明度为 128
ids.forEach(id => {
    const layer = stack.get_layer(id);
    layer.opacity = 128;
});

// 渲染合成
const composite = stack.render_composite();
```

### 示例 4: 创建渐变效果

```javascript
const stack = new LayerStack(800, 600);
const layerId = stack.add_layer("渐变");
const layer = stack.get_layer(layerId);
const pixels = layer.get_pixels();

// 创建垂直渐变
for (let y = 0; y < 600; y++) {
    const brightness = Math.floor((y / 600) * 255);
    for (let x = 0; x < 800; x++) {
        const idx = (y * 800 + x) * 4;
        pixels[idx] = brightness;     // R
        pixels[idx + 1] = 0;         // G
        pixels[idx + 2] = 255 - brightness; // B
        pixels[idx + 3] = 255;       // A
    }
}

layer.set_pixels(pixels);
const composite = stack.render_composite();
```

## 性能提示

1. **减少合成次数**: 只在需要时调用 `render_composite()`
2. **使用合适的混合模式**: Normal 模式最快，其他模式会有额外开销
3. **管理图层数量**: 过多图层会影响性能
4. **利用不透明度**: 使用 0 完全隐藏图层比删除更快
5. **批量操作**: 一次性修改多个图层的属性，然后统一合成

## 常见问题

### Q: 如何保存合成的图像？
```javascript
const composite = stack.render_composite();
const base64 = composite.get_base64();

// 下载为 PNG
const link = document.createElement('a');
link.href = base64;
link.download = 'image.png';
link.click();
```

### Q: 如何从文件加载图像？
```javascript
// 先使用 ImageProcessor 加载图像
const processor = ImageProcessor.new_from_bytes(fileBytes);
const pixels = processor.get_raw_pixels();

// 然后添加到图层堆栈
const id = stack.add_layer_from_pixels(pixels, "从文件加载");
```

### Q: 如何撤销操作？
当前版本不支持内置撤销功能。建议在外部管理图层状态：
```javascript
// 保存状态
const savedState = JSON.stringify({
    ids: stack.get_layer_ids(),
    names: stack.get_layer_names(),
    // ... 其他属性
});

// 恢复状态
// 根据保存的状态重建图层堆栈
```
