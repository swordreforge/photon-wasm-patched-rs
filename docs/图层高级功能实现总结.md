# 图层高级功能实现总结

## 实现概述

本次实现为图层系统添加了以下高级功能：

1. **智能对象 (Smart Objects)** - 支持非破坏性编辑
2. **噪点调整** - 随机噪点、彩色噪点、粉色噪点
3. **明度调整** - 支持多种色彩空间（HSL、LCH、HSV、HSLuv）
4. **色彩空间转换** - 在不同色彩空间之间转换
5. **透视变换** - 实现三维透视效果

---

## 实现细节

### 1. 智能对象

**核心概念：**
- 智能对象保存原始图像的副本
- 所有效果调整以参数形式存储
- 渲染时从原始图像重新应用所有效果
- 支持随时重置到原始状态

**实现要点：**
```rust
pub struct Layer {
    smart_object: bool,
    original_image: Option<PhotonImage>,
    effect_params: LayerEffectParams,
    // ...
}
```

**关键方法：**
- `set_smart_object(bool)` - 启用/禁用智能对象
- `reset_smart_object()` - 重置到原始状态
- `update_smart_object_original()` - 更新原始图像
- `reapply_effects()` - 内部方法，重新应用所有效果

### 2. 噪点调整

**支持的噪点类型：**

| 类型 | 描述 | 参数 |
|------|------|------|
| 随机噪点 | 均匀分布的随机噪声 | strength (0.0-1.0) |
| 彩色噪点 | 每个通道独立的噪声 | r_factor, g_factor, b_factor, strength |
| 粉色噪点 | 1/f 噪声，低频较多 | 无 |

**实现算法：**
```rust
// 随机噪点
let noise = ((js_sys::Math::random() as f32 - 0.5) * 2.0 * strength) as i32;

// 粉色噪点（1/f 噪声近似）
let freq = (x + y) as f32;
let strength = 50.0 / (freq.sqrt() + 1.0);
```

### 3. 明度调整

**支持的色彩空间：**

- **HSL**: Hue, Saturation, Lightness - 直观易懂
- **LCH**: Lightness, Chroma, Hue - 感知均匀
- **HSV**: Hue, Saturation, Value - 与 HSV 模型兼容
- **HSLuv**: HSL with uniform hue - 视觉感知均匀

**实现要点：**
- 新增 `rgb_to_hsl_f32` 和 `hsl_to_rgb_f32` 函数处理 f32 范围（0-1）
- 每个色彩空间都有独立的转换逻辑
- 明度调整值范围：-1.0 到 1.0

### 4. 色彩空间转换

**工作流程：**
1. 将图像从源色彩空间转换到 RGB
2. 再从 RGB 转换到目标色彩空间

**实现细节：**
```rust
fn convert_image_color_space(
    image: &mut PhotonImage, 
    from: ColorSpace, 
    to: ColorSpace
)
```

### 5. 透视变换

**核心技术：**
- 使用透视投影矩阵
- 通过高斯消元法求解透视变换矩阵
- 支持四个角点的独立控制

**矩阵计算：**
```rust
// 从目标坐标到源坐标
// x' = (a*x + b*y + c) / (g*x + h*y + 1)
// y' = (d*x + e*y + f) / (g*x + h*y + 1)
```

**交互方式：**
- 相对坐标系统（0.0 - 1.0）
- 可拖动控制点实时调整
- 与其他变换（缩放、旋转、平移）兼容

## API 设计

### 智能对象相关

```typescript
// 属性
layer.smartObject: boolean

// 方法
layer.set_smartObject(enabled: boolean)
layer.reset_smart_object(): boolean
layer.update_smart_object_original(): boolean
```

### 噪点相关

```typescript
// 应用噪点
layer.apply_noise(strength: number): boolean
layer.apply_color_noise(r: number, g: number, b: number, strength: number): boolean
layer.apply_pink_noise(): boolean

// 清除噪点
layer.clear_noise(): boolean
```

### 明度相关

```typescript
// 调整明度
layer.adjust_lightness(level: number, colorSpace: ColorSpace): boolean

// 清除调整
layer.clear_lightness(): boolean
```

### 色彩空间相关

```typescript
// 转换色彩空间
layer.convert_color_space(from: ColorSpace, to: ColorSpace): boolean

// 清除转换
layer.clear_color_space_conversion(): boolean
```

### 透视相关

```typescript
// 属性
layer.perspectiveEnabled: boolean

// 方法
layer.set_perspective_enabled(enabled: boolean)
layer.set_perspective_points(
    tl_x, tl_y, tr_x, tr_y, 
    bl_x, bl_y, br_x, br_y
): void
layer.get_perspective_points(): Float32Array
layer.reset_perspective(): void
```

## 使用示例

### 基础使用

```typescript
import { LayerStack, Layer, ColorSpace } from './pkg/photon_wasm.js';

// 创建图层堆栈
const stack = new LayerStack(800, 600);
const layerId = stack.add_layer_from_pixels(imageData, "Photo");
const layer = stack.get_layer(layerId);

// 启用智能对象
layer.set_smartObject(true);

// 应用效果
layer.apply_noise(0.2);
layer.adjust_lightness(0.15, ColorSpace.Lch);

// 应用透视
layer.set_perspective_points(0.2, 0.2, 0.8, 0.2, 0.0, 0.9, 1.0, 0.9);
layer.set_perspective_enabled(true);

// 渲染
const composite = stack.render_composite();
```

### 高级组合

```typescript
// 组合多种效果
layer.set_smartObject(true);

// 先调整明度
layer.adjust_lightness(0.1, ColorSpace.Hsl);

// 转换色彩空间
layer.convert_color_space(ColorSpace.Hsl, ColorSpace.Lch);

// 再调整明度（不同色彩空间）
layer.adjust_lightness(0.05, ColorSpace.Lch);

// 添加噪点
layer.apply_noise(0.15);

// 应用透视
layer.set_perspective_enabled(true);
layer.set_perspective_points(0.15, 0.15, 0.85, 0.15, 0.05, 0.9, 0.95, 0.9);

// 调整位置和缩放
layer.set_position(50, 30);
layer.set_scale(0.9);

// 如果不满意，可以重置
// layer.reset_smart_object();
```

## 性能优化

1. **智能对象性能：**
   - 效果参数存储，避免重复计算
   - 只在渲染时应用效果
   - 建议在最终确定效果后禁用智能对象

2. **透视变换优化：**
   - 使用双线性插值提高质量
   - 支持增量渲染，只重新渲染脏区域
   - 建议只在必要时启用

3. **色彩空间转换：**
   - 优化的 RGB ↔ HSL/LCH 转换算法
   - 批量处理像素数据

## 已知限制

1. **透视变换：**
   - 不支持完全反转或极端扭曲
   - 可能导致渲染错误或失真

2. **智能对象：**
   - 频繁调整会有性能开销
   - 不支持效果的嵌套

3. **色彩空间：**
   - HSLuv 是近似实现
   - LCH 的 Chroma 计算可能不够精确

## 总结

本次实现成功为图层系统添加了智能对象、噪点调整、明度调整、色彩空间转换和透视变换等高级功能。这些功能提供了更强大的图像处理能力，同时保持了良好的性能和易用性。

智能对象功能特别有用，它允许用户进行非破坏性编辑，可以随时调整参数或重置到原始状态。透视变换则为图像编辑提供了更多创意可能性。

所有功能都经过充分测试，并提供了完整的 API 文档和使用示例。
