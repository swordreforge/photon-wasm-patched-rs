根据代码探索结果，我来分析一下如何为这个项目加入图层功能。

  当前架构分析

  现有优势
   1. photon-rs 已提供基础的多图像操作能力（水印、混合模式）
   2. 支持多种混合模式，包括正片叠底、滤色、叠加等效果
   3. 高性能并行处理和 SIMD 加速能力
   4. 笔刷系统基于 tiny-skia，具备良好的渲染能力

  现有局限
   - 缺少完整的图层管理系统
   - 无法独立变换各个图层
   - 没有图层可见性、锁定等控制

  图层系统设计方案

  2. 主要功能模块

  2.1 图层管理
   - add_layer() - 添加新图层
   - remove_layer() - 删除图层
   - move_layer() - 调整图层顺序
   - duplicate_layer() - 复制图层
   - merge_down() - 向下合并图层
   - flatten() - 合并所有图层

  2.2 图层属性
   - set_layer_visibility() - 设置可见性
   - set_layer_opacity() - 设置不透明度
   - set_layer_blend_mode() - 设置混合模式
   - set_layer_transform() - 设置变换

  2.3 图层合成
   - render_composite() - 合成最终图像
   - render_layer_preview() - 渲染单个图层预览
   - incremental_render() - 增量渲染（优化性能）

  3. 性能优化策略

  3.1 增量合成
   - 只重新合成变化的图层
   - 使用 dirty region 检测
   - 缓存已渲染的图层

  3.2 并行合成
   pub fn render_composite_parallel(&self) -> PhotonImage {
       // 使用 Rayon 并行处理图层
       let mut composited = self.create_base_canvas();

       for layer in &self.layers {
           if !layer.visible { continue; }
    
           // 并行应用混合模式
           let rendered = rayon::spawn(move || {
               render_layer_to_canvas(layer)
           });
    
           // 合并到最终图像
           blend_images(&mut composited, &layer.image,
   layer.blend_mode, layer.opacity);
       }

       composited
   }

  3.3 SIMD 优化
   - 对常用混合模式（Normal、Multiply、Screen）使用 SIMD 加速
   - 利用现有的 simd.rs 模块扩展

       #[wasm_bindgen]
       pub fn enable_layer_system(&mut self, width: u32, height:
   u32) {
           let background = photon_rs::PhotonImage::new(
               self.image.raw_pixels.clone(),
               self.image.width,
               self.image.height,
           );
           self.layer_stack = Some(LayerStack::new(width, height,
   background));
       }

       #[wasm_bindgen]
       pub fn add_new_layer(&mut self) -> usize {
           if let Some(stack) = &mut self.layer_stack {
               let new_layer = Layer::new(
                   stack.canvas_width,
                   stack.canvas_height,
               );
               stack.add_layer(new_layer)
           } else {
               0
           }
       }
   }

  5. 实现优先级建议

  第一阶段（核心功能）
   1. 实现 Layer 和 LayerStack 基础结构
   2. 实现图层的基本 CRUD 操作
   3. 实现简单的图层合成（从下到上叠加）

  第二阶段（变换与属性）
   1. 实现图层变换（位置、缩放、旋转）
   2. 实现混合模式应用
   3. 实现不透明度和可见性控制

  第三阶段（高级功能）
   1. 实现图层蒙版
   2. 实现调整图层（仅影响下方图层）
   3. 实现图层组

  第四阶段（性能优化）
   1. 实现增量渲染
   2. 实现图层缓存
   3. 实现并行合成

  总结

  这个图层系统设计方案：
   - ✅ 充分利用现有的 photon-rs 混合模式和并行能力
   - ✅ 与现有笔刷系统无缝集成
   - ✅ 采用渐进式实现，降低开发复杂度
   - ✅ 考虑了性能优化（增量渲染、并行合成）
   - ✅ 保持向后兼容，不影响现有功能

✦ 建议先实现第一阶段的核心功能，验证设计可行性后再逐步扩展高级特性。
