# 图层系统第二阶段使用指南

## 概述

图层系统第二阶段在第一阶段的基础上，新增了以下核心功能：

1. **图层变换** - 支持位置、缩放、旋转、翻转等变换操作
2. **扩展混合模式** - 新增 13 种 Photoshop 风格的混合模式
3. **不透明度控制** - 精确控制图层不透明度
4. **可见性控制** - 控制图层的显示/隐藏

## 新增功能详解

### 1. 图层变换

#### 1.1 位置变换

```javascript
// 设置位置
layer.set_position(x, y);

// 单独设置 X 位置
layer.set_position_x(x);

// 单独设置 Y 位置
layer.set_position_y(y);

// 获取位置
const x = layer.position_x;
const y = layer.position_y;
```

**参数说明：**
- `x, y`: 位置偏移量（像素），相对于画布中心

#### 1.2 缩放变换

```javascript
// 设置均匀缩放
layer.set_scale(scale);

// 单独设置 X 缩放
layer.set_scale_x(scaleX);

// 单独设置 Y 缩放
layer.set_scale_y(scaleY);

// 获取缩放
const scaleX = layer.scale_x;
const scaleY = layer.scale_y;
```

**参数说明：**
- `scale`: 缩放比例，1.0 为原始大小
- 支持非均匀缩放（X 和 Y 方向独立缩放）

#### 1.3 旋转变换

```javascript
// 设置旋转角度
layer.set_rotation_degrees(angle);

// 获取旋转角度
const angle = layer.rotation_degrees;
```

**参数说明：**
- `angle`: 旋转角度（度），0-360
- 旋转中心为画布中心

#### 1.4 翻转变换

```javascript
// 水平翻转
layer.set_flip_horizontal(true);

// 垂直翻转
layer.set_flip_vertical(true);

// 获取翻转状态
const flipH = layer.flip_horizontal;
const flipV = layer.flip_vertical;
```

#### 1.5 变换原点

```javascript
// 设置变换原点
layer.set_origin(originX, originY);

// 单独设置 X 原点
layer.set_origin_x(originX);

// 单独设置 Y 原点
layer.set_origin_y(originY);

// 获取变换原点
const originX = layer.origin_x;
const originY = layer.origin_y;
```

**参数说明：**
- `originX, originY`: 变换原点坐标（0-1），相对于图层中心
- (0.5, 0.5) 为默认中心点

#### 1.6 重置变换

```javascript
// 重置所有变换为默认值
layer.reset_transform();
```

### 2. 混合模式

系统现在支持 22 种混合模式，包括 Photoshop 风格的高级混合模式。

#### 2.1 基础混合模式（第一阶段）

```javascript
const blendModes = {
    Normal: BlendMode.Normal,
    Multiply: BlendMode.Multiply,
    Screen: BlendMode.Screen,
    Overlay: BlendMode.Overlay,
    SoftLight: BlendMode.SoftLight,
    HardLight: BlendMode.HardLight,
    Difference: BlendMode.Difference,
    Exclusion: BlendMode.Exclusion,
    Lighten: BlendMode.Lighten,
    Darken: BlendMode.Darken,
};
```

#### 2.2 扩展混合模式（第二阶段新增）

```javascript
const extendedBlendModes = {
    ColorDodge: BlendMode.ColorDodge,      // 颜色减淡
    ColorBurn: BlendMode.ColorBurn,        // 颜色加深
    LinearDodge: BlendMode.LinearDodge,    // 线性减淡（加法）
    LinearBurn: BlendMode.LinearBurn,      // 线性加深
    VividLight: BlendMode.VividLight,      // 亮光
    LinearLight: BlendMode.LinearLight,    // 线性光
    PinLight: BlendMode.PinLight,          // 点光
    HardMix: BlendMode.HardMix,            // 实色混合
    Hue: BlendMode.Hue,                    // 色相
    Saturation: BlendMode.Saturation,      // 饱和度
    Color: BlendMode.Color,                // 颜色
    Luminosity: BlendMode.Luminosity,      // 明度
};
```

#### 2.3 使用混合模式

```javascript
// 设置混合模式
layer.set_blend_mode(BlendMode.Screen);

// 获取混合模式
const mode = layer.blend_mode;
```

**混合模式效果说明：**

| 混合模式 | 效果描述 | 适用场景 |
|---------|---------|---------|
| Normal | 正常覆盖 | 默认模式 |
| Multiply | 正片叠底 | 变暗，模拟墨水效果 |
| Screen | 滤色 | 变亮，模拟光线效果 |
| Overlay | 叠加 | 增强对比度 |
| ColorDodge | 颜色减淡 | 极度变亮 |
| ColorBurn | 颜色加深 | 极度变暗 |
| VividLight | 亮光 | 强对比度 |
| Hue | 色相 | 只改变色相 |
| Saturation | 饱和度 | 只改变饱和度 |
| Color | 颜色 | 综合色相和饱和度 |
| Luminosity | 明度 | 只改变明度 |

### 3. 不透明度控制

```javascript
// 设置不透明度 (0-255)
layer.set_opacity(128);  // 50% 不透明度

// 获取不透明度
const opacity = layer.opacity;  // 0-255

// 转换为百分比
const opacityPercent = (opacity / 255) * 100;
```

**注意事项：**
- 不透明度值范围：0（完全透明）到 255（完全不透明）
- 不透明度与混合模式协同工作
- 在渲染时，不透明度会影响最终合成效果

### 4. 可见性控制

```javascript
// 设置可见性
layer.set_visible(true);   // 显示图层
layer.set_visible(false);  // 隐藏图层

// 获取可见性
const visible = layer.visible;

// 快速切换
const isVisible = layer.visible();
layer.set_visible(!isVisible);
```

**注意事项：**
- 隐藏的图层在 `render_composite()` 时不会被渲染
- 可见性独立于不透明度（隐藏的图层即使不透明度为 255 也不会显示）

## 使用示例

### 示例 1：创建并变换图层

```javascript
// 创建图层堆栈
const stack = LayerStack.new_js(800, 600);

// 添加背景图层
const bgPixels = createWhitePixels(800, 600);
stack.add_layer_from_pixels(bgPixels, 'Background');

// 添加图像图层
const imagePixels = loadPixelsFromImage('photo.jpg');
const layerId = stack.add_layer_from_pixels(imagePixels, 'Photo');

// 获取图层并应用变换
const layer = stack.get_layer(layerId);
layer.set_position(100, 50);       // 平移
layer.set_scale(1.5);              // 放大 1.5 倍
layer.set_rotation_degrees(30);    // 旋转 30 度
layer.set_opacity(200);            // 80% 不透明度

// 渲染合成图像
const composited = stack.render_composite();
displayImage(composited);
```

### 示例 2：使用不同混合模式

```javascript
// 创建两个重叠的图层
const layer1Id = stack.add_layer_from_pixels(redPixels, 'Red Layer');
const layer2Id = stack.add_layer_from_pixels(bluePixels, 'Blue Layer');

const layer1 = stack.get_layer(layer1Id);
const layer2 = stack.get_layer(layer2Id);

// 设置不同混合模式
layer1.set_blend_mode(BlendMode.Normal);
layer2.set_blend_mode(BlendMode.Multiply);  // 正片叠底效果

// 渲染
const result = stack.render_composite();
```

### 示例 3：动画变换效果

```javascript
let angle = 0;
let scale = 1.0;
let increasing = true;

function animate() {
    const layer = stack.get_layer(activeLayerId);

    // 旋转动画
    angle = (angle + 2) % 360;
    layer.set_rotation_degrees(angle);

    // 缩放动画
    if (increasing) {
        scale += 0.01;
        if (scale >= 1.5) increasing = false;
    } else {
        scale -= 0.01;
        if (scale <= 0.8) increasing = true;
    }
    layer.set_scale(scale);

    // 渲染并显示
    const composited = stack.render_composite();
    updateCanvas(composited);

    requestAnimationFrame(animate);
}

animate();
```

### 示例 4：混合模式渐变效果

```javascript
const modes = [
    BlendMode.Normal,
    BlendMode.Multiply,

    BlendMode.Overlay,
```

## 性能优化建议

### 1. 避免频繁变换

```javascript
// ❌ 不好的做法 - 每次渲染都重新计算变换
function render() {
    layer.set_position(Math.random() * 100, Math.random() * 100);
    const result = stack.render_composite();
}

// ✅ 好的做法 - 只在需要时更新变换
let lastX = 0;
let lastY = 0;

function updatePosition(x, y) {
    if (x !== lastX || y !== lastY) {
        layer.set_position(x, y);
        lastX = x;
        lastY = y;
        const result = stack.render_composite();
        updateCanvas(result);
    }
}
```

### 2. 批量更新变换

```javascript
// ✅ 好的做法 - 一次性设置所有变换属性
layer.set_position(100, 50);
layer.set_scale(1.5);
layer.set_rotation_degrees(30);
layer.set_blend_mode(BlendMode.Screen);
layer.set_opacity(200);
// 最后一次性渲染
const result = stack.render_composite();
```

### 3. 隐藏不需要的图层

```javascript
// 隐藏临时图层以提高渲染性能
tempLayer.set_visible(false);
const result = stack.render_composite();

// 需要时再显示
tempLayer.set_visible(true);
```

## 技术细节

### 变换矩阵实现

图层变换使用 2D 仿射变换矩阵实现，支持：

- 平移（Translation）
- 缩放（Scale）
- 旋转（Rotation）
- 翻转（Flip）

变换矩阵的数学表示：

```
| a  c  tx |
| b  d  ty |
| 0  0  1  |
```

其中：
- `a, d`: 缩放因子
- `b, c`: 倾斜因子（目前为 0）
- `tx, ty`: 平移量

### 双线性插值

变换后的图像使用双线性插值算法进行重采样，确保平滑的图像质量：

```rust
// 对每个像素进行反向映射和双线性插值
let (src_x, src_y) = inv_transform.transform_point(x as f32, y as f32);
let interpolated = bilinear_interpolate(src_pixels, src_x, src_y);
```

### 混合模式实现

#### 像素级混合模式

对于简单的混合模式（如 Multiply, Screen 等），直接在像素级别计算：

```rust
fn blend_pixels(bottom: u8, top: u8, mode: BlendMode) -> u8 {
    match mode {
        BlendMode::Multiply => (bottom as f32 * top as f32 / 255.0) as u8,
        BlendMode::Screen => 255 - (255 - bottom) * (255 - top) / 255,
        // ...
    }
}
```

#### HSL 混合模式

对于 Hue, Saturation, Color, Luminosity 等混合模式，需要：

1. 将 RGB 转换为 HSL 颜色空间
2. 在 HSL 空间进行混合
3. 转换回 RGB 颜色空间

```rust
fn blend_hsl<F>(bottom: &mut PhotonImage, top: &PhotonImage, blend_fn: F)
where
    F: Fn(f32, f32, f32, f32, f32, f32) -> (f32, f32, f32),
{
    // RGB → HSL
    let (bh, bs, bl) = rgb_to_hsl(bottom_r, bottom_g, bottom_b);
    let (th, ts, tl) = rgb_to_hsl(top_r, top_g, top_b);

    // 在 HSL 空间混合
    let (h, s, l) = blend_fn(bh, bs, bl, th, ts, tl);

    // HSL → RGB
    let (r, g, b) = hsl_to_rgb(h, s, l);
}
```

## 常见问题

### Q1: 为什么变换后的图像质量下降了？

A: 这是正常的插值效果。可以通过以下方式改善：

1. 使用更高分辨率的源图像
2. 避免过度缩放（特别是放大）
3. 使用 `set_scale()` 进行均匀缩放而非非均匀缩放

### Q2: 如何实现平滑的动画效果？

A: 使用 `requestAnimationFrame` 并逐步更新变换参数：

```javascript
let currentAngle = 0;
let targetAngle = 90;

function animate() {
    const diff = targetAngle - currentAngle;
    currentAngle += diff * 0.1;  // 缓动效果

    layer.set_rotation_degrees(currentAngle);
    const result = stack.render_composite();
    updateCanvas(result);

    if (Math.abs(diff) > 0.1) {
        requestAnimationFrame(animate);
    }
}
```

### Q3: 某些混合模式效果不明显？

A: 这取决于：

1. **图层内容** - 某些混合模式需要特定的图像内容才能显示效果
2. **不透明度** - 尝试调整不透明度以增强效果
3. **图像对比度** - 高对比度的图像混合效果更明显

### Q4: 如何重置单个变换而不是全部？

A: 单独设置需要重置的变换属性：

```javascript
// 只重置位置
layer.set_position(0, 0);

// 只重置缩放
layer.set_scale(1.0);

// 只重置旋转
layer.set_rotation_degrees(0);

// 重置所有变换
layer.reset_transform();
```
